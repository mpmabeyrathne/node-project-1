# Booking System API

Production-oriented booking backend built with Node.js, TypeScript,
Express, PostgreSQL, Redis, RabbitMQ and AWS.

## Features

- Room management
- Booking date validation
- Overlapping booking prevention
- PostgreSQL transactions and row locking
- Redis caching
- Mock payment workflow
- RabbitMQ booking-confirmed events
- Background worker
- Graceful shutdown
- Rate limiting and security headers
